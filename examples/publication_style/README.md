# Publication Style Example

This example demonstrates how to customize plot appearance for publication using style presets, palettes, and export formats.

## Style presets

- **paper** - High DPI (300), compact size (8x6), publication-ready
- **presentation** - Large figure (16x9), bold fonts, projector-friendly
- **dark** - Dark background with light text

## Color palettes

- **default** - matplotlib tab10
- **colorblind** - Wong's palette (colorblind-friendly)
- **vivid** - High saturation colors
- **muted** - Desaturated, professional colors

## Export formats

- **png** - Raster format (default)
- **svg** - Vector graphics (scalable)
- **pdf** - Vector format (publication)

## Running the example

```bash
python generate_data.py
python main.py
```

## Output files

- `paper_style.png` - Publication-ready PNG
- `presentation_style.png` - Large format for slides
- `dark_theme.png` - Dark background version
- `colorblind_palette.png` - Accessible colors
- `vector_output.svg` - Scalable vector graphics
