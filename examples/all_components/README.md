# All Components Example

This example demonstrates all four mr-dapa visualization components.

## Components demonstrated

1. **LinesComponent** - Time-series line plots (x and y positions)
2. **MapComponent** - 2D position map with trajectory trails
3. **ScatterComponent** - Phase plot (x vs y)
4. **FillComponent** - Filled area between multiple value series

## Running the example

```bash
python generate_data.py
python main.py
```

## Output

A single figure with all four component types displayed in separate subplots.
