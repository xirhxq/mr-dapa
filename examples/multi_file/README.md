# Multi-File Adapter Example

This example demonstrates how to load and merge data from multiple JSON files using the `MultiFileAdapter`.

## Running the example

```bash
python generate_data.py
python main.py
```

## What it demonstrates

- Loading data from multiple JSON files
- Each file can contain one or more robots
- Files are automatically merged into a single dataset

## Use cases

- Data logged separately per robot
- Distributed data collection
- Combining data from multiple experiments
