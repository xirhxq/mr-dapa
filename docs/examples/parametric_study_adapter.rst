Parametric Study Adapter Example
================================

Location
--------

``examples/parametric_study_adapter/``

Run
---

.. code-block:: bash

   python examples/parametric_study_adapter/generate_data.py
   python examples/parametric_study_adapter/main.py

This example draws final coverage and completion time against swept parameter
values from a ``summary.json`` file using ``ParametricStudyAdapter``.
